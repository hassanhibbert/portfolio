Plantbox

In progress

An automatic plant-watering system that actually works. It runs on ESP8266 hardware with moisture sensors and pumps. Right now I'm replacing the Blynk cloud with my own backend.

  • The device talks to a Spring Boot service over MQTT.
  • Sensor history is stored in Postgres, with a dashboard to water plants on demand.
  • ESP8266
  • C++
  • MQTT
  • Spring Boot
  • React
