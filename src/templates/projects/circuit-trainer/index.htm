Circuit Trainer

Demo ↗

A workout app I built for my own training: guided circuit timers, a 12-week kettlebell program, set logging and goals. It works offline and syncs when you're back online.

  • Every query is scoped to its owner, so asking for someone else's data gets a 404, not their data.
  • Offline sync is idempotent: a workout that uploads twice is saved once.
  • 54 tests across unit, web and database layers. Database tests run against a throwaway Postgres container (Testcontainers), not an in-memory fake.
  • Java 21
  • Spring Boot
  • PostgreSQL
  • Flyway
  • React
  • Docker
