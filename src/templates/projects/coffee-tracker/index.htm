Coffee Tracker

For dialing in the cappuccinos I make at home. It logs beans, equipment, grind size, ratio, and how the cup turned out.

  • The client's TypeScript types are generated from the API's spec, so changing a Java class breaks the build instead of production.
  • Each brew method knows which grind sizes make sense. Break that rule and the API explains why.
  • Tested at every layer, from JUnit to React Testing Library.
  • Java 21
  • Spring Boot
  • PostgreSQL
  • OpenAPI
  • React
  • TypeScript
